# Windows development

The Windows continuation guide starts at
[`docs/windows/README.md`](docs/windows/README.md).

Use that index for:

- the verified project status and Windows scope;
- native Windows setup and build commands;
- the ordered implementation plan;
- the OBS-first and native virtual-camera paths; and
- the validation matrix and release gate.

The primary validation target is Windows 11 x64. Windows 10 and Windows on Arm
are compatibility targets after the x64 client is stable.
